# Hareesh Moyalali Complete Website

This is a separate fictional, traditional-Kerala-inspired political satire website.

## Upload these files to a NEW GitHub repository

- index.html
- style.css
- script.js
- moyalali.png

Do not upload these files into the Sreebha Storybook repository.

## GitHub Pages setup

1. Create a new public repository named `hareesh-moyalali`.
2. Upload all four files.
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Select branch `main` and folder `/root`.
6. Save and wait a few minutes.

Your website address will be:

https://YOUR-GITHUB-USERNAME.github.io/hareesh-moyalali/

## Comment form

The form has only:
- Name
- Comment

Visitors do not need to enter an email address.

GitHub Pages cannot store comments by itself. The form is prepared for Formspree.
To receive comments:

1. Open https://formspree.io
2. Create a free form.
3. Copy your endpoint.
4. Open `index.html` in GitHub.
5. Replace `https://formspree.io/f/YOUR_FORMSPREE_ID`
   with your actual Formspree endpoint.
6. Commit the change.

The website is fictional satire and is not a real business, political campaign,
political organisation, endorsement or factual historical account.
